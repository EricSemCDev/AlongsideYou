# Controles

## Ações

| Ação | Teclado e mouse | Controle |
|---|---|---|
| Mover o Al | `WASD` ou setas | Analógico esquerdo (Al ativo) |
| Pegar, largar e encaixar bloco | `Espaço` | A / Cruz |
| Girar face do bloco | `Q` / `E` | LB / RB (L1 / R1) |
| Mover o Finn | Segurar clique esquerdo (vai até o cursor) | Analógico esquerdo (Finn ativo) |
| Roda de operadores | Segurar clique direito perto da tocha, apontar e soltar | Segurar A / Cruz perto da tocha, apontar com o analógico e soltar |
| Trocar de personagem (Solo) | Não se aplica (controla os dois) | Y / Triângulo |
| Pausar | `ESC` | Start |
| Avançar fala do tutorial | `Espaço`, `Enter` ou clique | A / Cruz |
| Pular o tutorial | Segurar `TAB` | Segurar SELECT |
| Voltar nos menus | `ESC` | B / Bola |

> Os ícones de botão que aparecem no mundo e nas falas do tutorial trocam sozinhos entre teclado, Xbox, PlayStation e Switch, conforme o último dispositivo usado.

---

## Câmera

Câmera fixa por fase, enquadrando o mapa inteiro. No tutorial ela se move e dá zoom suave para mostrar cada elemento, depois volta ao enquadramento original. Um tremor curto marca o erro na conta e a barreira abrindo.

---

## Menus

- **Menu principal:** Jogar (abre Solo, Co-op e Voltar), Configurações, Créditos e Sair do Jogo
- **Menu de pausa:** Continuar, Reiniciar Fase e Voltar ao Menu
- **Tela de resultado:** estrelas da fase, Próxima fase e Refazer
- **Créditos:** texto subindo como em filme; segurar S (teclado) ou para baixo (controle) acelera; ESC ou B volta. A dica na tela muda conforme o dispositivo
- Todos os menus funcionam com mouse, teclado e controle

---

## Fluxo de Telas

| De | Para | Ação |
|---|---|---|
| Menu principal | Escolha de modo | Jogar |
| Escolha de modo | Prólogo | Solo ou Co-op |
| Fase | Menu de pausa | ESC ou Start |
| Menu de pausa | Fase | Continuar (ou ESC / Start / B) |
| Menu de pausa | Fase reiniciada | Reiniciar Fase |
| Menu de pausa | Menu principal | Voltar ao Menu |
| Fase | Tela de resultado | Coletar a Fagulha de Luz |
| Tela de resultado | Próxima fase | Próxima fase |
| Tela de resultado | Mesma fase | Refazer |
| Fase | Mesma fase (do zero) | Derrota (ansiedade ou tentativa esgotada) |
| Fase 10 concluída | Créditos | Próxima fase |
| Créditos | Menu principal | Fim da rolagem, ESC ou B |
| Menu principal | Créditos | Créditos |
